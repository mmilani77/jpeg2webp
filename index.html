    Le foto convertite compaiono qui.

    La conversione avviene nel tuo dispositivo: le foto non lasciano il telefono o il computer. La rotazione EXIF viene applicata ai pixel, poi il file viene ripulito di tutto ciò che non è immagine: EXIF, GPS, XMP, profilo colore, manifesti C2PA. La compressione usa libwebp alla massima efficienza, quindi è più lenta ma i file sono più leggeri. Le PNG mantengono la trasparenza.
